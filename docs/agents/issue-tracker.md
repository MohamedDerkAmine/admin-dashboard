# Issue Tracker

This repo tracks work in GitHub Issues for `MohamedDerkAmine/admin-dashboard`.

Use the GitHub CLI from the repository root:

```powershell
gh issue list
gh issue view <number>
gh issue create --title "<title>" --body-file <file> --label ready-for-agent
```

PRDs should be published as GitHub issues and labeled `ready-for-agent` when they are fully specified.
